# Space Inviders

Браузерная аркада на **Nuxt 4, Vue 3 и TypeScript**. Три вида анимированных пиксельных котят на Canvas, синтезированный звук, 55 космических котят в каждой волне, разрушаемые укрытия, бонусный Соник и три уровня сложности. Интерфейс адаптирован для телефона; рекорд и пять последних полётов сохраняются в localStorage.

## Запуск

Требу*ется Node.js 22.12+ и npm.

```sh
npm install
npm run dev
```

Открыть адрес, напечатанный Nuxt (обычно http://localhost:3000).

```sh
npm test           # тесты симуляции
npm run typecheck  # проверка TypeScript и Vue
npm run build      # production SSR-сборка
npm run preview    # запуск production-сборки
npm run generate   # статическая версия в .output/public
```

## Управление

- ← / → или A / D — движение.
- Пробел — огонь; можно удерживать.
- P / Escape / Enter — пауза или продолжение.
- R — новый полёт.
- На телефоне — кнопки движения и огня под игровым полем.

При переключении вкладки или потере фокуса игра автоматически приостанавливается. Кнопки внизу игрового поля управляют звуком и полноэкранным режимом. Сложность меняется перед началом полёта. Рекорды доступны в верхнем меню и на пульте управления. При недоступном localStorage игра работает без сохранений.

## Структура

- `app/game/engine.ts` — независимая симуляция, столкновения и волны.
- `app/game/kittens.ts` — общие спрайты котят для поля и интерфейса.
- `app/game/render.ts` — Canvas, спрайты, частицы и звёзды.
- `app/components/ArcadeGame.vue` — игровой цикл, управление, звук и сохранения.
- `app/app.vue` — оболочка и инструкция.
- `app/assets/css/main.css` — адаптивное оформление.

Игровые изображения и звуки создаются кодом. Шрифты Google Fonts необязательны: доступны системные альтернативы.

Вдохновлено классической Space Invaders: [история игры от TAITO](https://artsandculture.google.com/story/the-evolution-of-space-invaders/wAVxCu_0BaX0aw?hl=en-US).

## GitHub Pages

Workflow `.github/workflows/deploy.yml` проверяет тесты и TypeScript, собирает статическую версию и публикует её при каждом обновлении `main`. В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**.

Базовый путь определяется настройками Pages. Для локальной проверки сборки в подпапке:

```sh
NUXT_APP_BASE_URL=/space-inviders/ npm run generate
```

Готовый сайт находится в `.output/public`. Сервер Node.js для опубликованной игры не требуется.
